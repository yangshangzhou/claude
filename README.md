# X Post Browser MCP

This service publishes posts through the X web interface with Playwright. It does not call the X API `POST /2/tweets` endpoint, so it does not depend on X API posting credits.

## Render environment variable

Set:

`X_STORAGE_STATE`

Value: the complete JSON generated by `login_x.py` after logging into X locally.

Do not put the JSON in GitHub. It contains authentication cookies.

## Local session generation

Install dependencies and Chromium, then run:

```bash
pip install -r requirements.txt
playwright install chromium
python login_x.py
```

A Chromium window opens. Log into X manually. After you reach the normal X home page, return to the terminal and press Enter. The script creates `x_state.json`.

Copy the complete contents of `x_state.json` into the Render environment variable `X_STORAGE_STATE`, then redeploy.

## Endpoints

- `GET /` health check
- `GET /mcp/status` browser-session status
- `POST /mcp/create_post` with `{ "text": "your post" }`

The service rejects empty posts and posts longer than 280 characters.
